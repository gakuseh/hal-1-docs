Detailed Description

SPI and delay callbacks that connect the Bosch BMI323 driver to the STM32 HAL.

The Bosch driver calls these through bmi3_dev, with ptr pointing at the sensor's BMIobjPtr. Each of the three sensors has its own TX/RX buffer pair. Transfers are blocking HAL calls with a 5 s timeout.

uint8_t * data,
uint32_t len,
void * ptr )

Bosch read callback: reads len bytes starting at register reg.

Sends reg | 0x80, clocks len + 1 bytes, and copies everything after the address byte into data. The Bosch driver already adds the BMI323's dummy byte to len.

Parameters
regRegister address.
[out]dataDestination.
lenNumber of bytes to read.
ptrThe sensor's BMIobjPtr.
Returns
Always 0, even if the SPI transfer failed.
