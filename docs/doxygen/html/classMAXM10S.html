Detailed Description

MAX-M10S GPS: reads NMEA over I2C and parses it with TinyGPSPlus.

Init() sets the airborne (<4 g) dynamic model and enables GGA, RMC and GSA output on I2C. Each update() drains the module's buffer and parses whole sentences.

◆ Init()

uint8_t MAXM10S::Init ( I2C_HandleTypeDef * hi2c)

Releases the module from reset, checks it answers, and sends the config.

Releases GPS_RST, waits 500 ms for boot, reads the bytes-available register to confirm the module is on the bus, then sends a UBX-CFG-VALSET that sets the airborne (<4 g) model and enables GGA, RMC and GSA on I2C. The config is saved to the module's RAM, battery-backed RAM and flash.

Parameters
hi2cI2C bus (&hi2c4 on HAL-1).
Returns
0 on success, 1 if the module did not answer. The config write's result is not checked.

◆ update()

uint8_t MAXM10S::update ( )

Reads everything the module has buffered and parses it.

Reads up to 1024 bytes per call (I2C timeouts of 50 and 100 ms). Every complete sentence updates the satellite count, HDOP and validity flags; position, altitude, speed and time update when they change.

Returns
An UpdateStatus value.
