◆ CTRLs()

void CTRLs ( void * arg)

Entry point of the CTRLs task, defined in main.cpp.

Created in MX_FREERTOS_Init() at Realtime priority with a 12 KB stack. Idles until ALLOW_ACTUATION is set at burnout, then runs CTRLs_PID() while STATE_BACKUP_PID is set and CTRLs_STATESPACE() once ignition has latched. updateDataTask() wakes it with a task notification after each sensor frame.

◆ g_ctrls_enabled

volatile bool g_ctrls_enabled
extern

Master enable for the state-space controller. Starts true. Cleared by the pad tare, GND command 217, apogee detection, and the actuation lockouts.

Bug
Only Telemetry::processPyros() sets it back to true, and nothing calls that. The pad tare (after 3 minutes still on the pad) clears it, so in a normal launch the state-space controller never actuates: CTRLs_STATESPACE() returns at its first check.
