Detailed Description

Append-only text logging to HAL1_LOG.TXT on the SD card (FatFs).

Every write takes one shared mutex and calls f_sync() straight away, so a power loss loses at most the line being written, but each call can block for as long as the card takes to sync.

◆ SD_Init()

int8_t SD_Init ( )

Mounts the card and opens HAL1_LOG.TXT for appending.

Call once before any SD_Log* call. FC_Init() retries it every 100 ms until it succeeds.

Returns
0 on success or if already open; -20 if the FatFs driver was not linked (MX_FATFS_Init() not called first); -(FRESULT) if mounting failed (for example -3 = FR_NOT_READY; check sd_init_fail_step); -(100 + FRESULT) if opening the file failed after mounting.
