Detailed Description

template<typename T>
class Vector3D< T >

a 3D vector class. Vector3D<instantiation type> variable_name(x,y,z);

Mixed-type arithmetic promotes to the common type, so a float vector plus a double vector gives a double vector.

Template Parameters
Tinstantiation type. float creates a float vector, int produces an int vector, etc.
Warning
The firmware builds with -fno-exceptions, so operator/() and normalized(), which throw, would fail to compile if used.
