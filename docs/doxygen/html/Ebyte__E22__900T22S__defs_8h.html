Detailed Description

Command bytes, register bit fields, and the config struct for the E22-900T22S.

Register field names follow <register>_<bits>_<function>, so R0_765_E22_UART_BAUD is REG0 bits 7–5. OR the fields together to build a register value; Telemetry::Init() shows the HAL-1 settings.
