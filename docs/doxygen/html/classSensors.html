Detailed Description

Owns every sensor driver and publishes their readings each cycle.

One global instance, S in main.cpp. FC_Init() calls Init() until it returns STATUS_OK, then updateSensorTask() calls Update() at up to 500 Hz.

Warning
This class has its own Servo_Axon_Mini_MKII, separate from the global Servos that the CTRLs task drives. Both write TIM3 and read ADC3, and Update() reads the feedback angles from this one.

◆ Init()

int8_t Sensors::Init ( )

Initializes the IMUs, barometers, GPS, servos and magnetometer.

The IMUs and barometers run in triple-redundant mode. A servo or magnetometer failure does not fail the result.

Returns
STATUS_OK, or STATUS_SENSOR_FAIL if any IMU, barometer or the GPS failed. The servo check takes about 3 s, so each failed attempt is slow.
Bug
The body of if (mag.Init() != 0) is commented out, so that if now guards the next statement: g_telemNow and g_telemPrev are zeroed only when the magnetometer fails to initialize.

◆ Update()

int8_t Sensors::Update ( )

Reads every sensor and publishes the results.

Updates the IMUs, barometers and GPS, then detects liftoff (total acceleration above LIFTOFF_ACCEL_G for LIFTOFF_SUSTAIN_MS) to start the flight clock. Under g_ctrls_sensor_mutex (20 ms timeout) it writes g_telemNow (GPS, altitude, temperature, acceleration, rates, servo feedback), g_GPS, and g_SensorData with fresh set. The IMU's Y and Z axes are swapped so Z runs along the rocket. If the mutex is busy the results are dropped for this cycle.

Returns
STATUS_OK, always.
