Detailed Description

Radio protocol between the flight computer (FC) and the ground station (GND).

Defines the two packet payloads (telemetryData, FC → GND, and GndStationData, GND → FC), the framing bytes, radio addresses and command bytes, and the Telemetry class that frames packets and decides when to transmit and when to listen.

Every constant and struct here must match HAL-1-GND (RADIO_DEFNS.h and Radio.h) byte for byte.

See also
Ebyte_E22_900T22S.h for the module driver.
docs/ARCHITECTURE.md for the frame layout and the Radio duty cycle.

enum pyroActivateKeys

32-bit keys GND can send in GndStationData::pyroActivation.

Despite the names, Telemetry::processPyros() maps them to controller modes, not pyro channels. That function is never called, so the keys currently do nothing.
