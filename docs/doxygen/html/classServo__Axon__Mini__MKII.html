Detailed Description

Both canard servos: open-loop PWM commands and analog angle feedback.

Commands map angle to pulse width at 1500 µs + 5.56 µs per degree (TIM3 counts at 2 MHz). Feedback reads each servo's analog position output on ADC3 and converts volts to degrees at 360° per 3.3 V, relative to the voltage captured at centre during Init().

There are two instances: the global Servos in main.cpp, which the CTRLs task commands, and the one inside Sensors, which Sensors::Update() reads.

Warning
S1 drives TIM3 CH1 (PC6, which CubeMX names SERVO2_PWM) but reads ADC3 INP0 (PC2, named SERVO1_ENC); S2 is crossed the same way. In CubeMX's naming, each servo's command and feedback belong to different connectors. Telemetry::receiveCommands() swaps the GND offsets, probably to compensate.

bool Servo_Axon_Mini_MKII::Init ( SAsym< float > AngOffset,
PRECISION precision,
bool debug )

Starts PWM, centres both servos, records the zero reference, and checks they hold position.

Init({offset 1, offset 2} (degrees), PRECISION::xxx, true/false);
Return true if the rotated degree matches commanded degree. Initializing servo outputs PWM to servo pin, then checks the encoder voltage for rotated angle. Matching angle indicates no fault in motor hardware.
.

Calibrates ADC3, starts TIM3 CH1 and CH2, commands 0°, waits 200 ms, and records the feedback voltages as zero. Then, for up to 3 s at 200 Hz, it commands the offset angles and checks the feedback is within precision.

Parameters
AngOffsetTrim added to every command (deg).
precisionTolerance for the check.
debugStored in the config; not used.
Returns
true if both servos were within tolerance.
Warning
At TENTH_DEGREE the tolerance is about one ADC count (0.9 mV), so the check can fail on noise alone. With no servos attached it always fails, and FC_Init() retries it forever.
Returns
bool value:
return true = no hardware fault
return false = hardware fault or tolerance not nominal

SAsym< float > Servo_Axon_Mini_MKII::readRawVoltage ( )
private

Reads both feedback voltages from ADC3 and smooths them.

Starts one scan conversion, polls both channels (5 ms timeout each), converts to volts, and applies an EMA with α = 0.5.

Returns
Smoothed voltages (V), no offset applied.
Note
The EMA state is a function-local static, so every instance shares it. The comment in the source says α = 0.1.

Commands both servos and refreshes the feedback data.

Servo_Axon_Mini_MKII::Update(<float, -180.0f to +180.0f>)
This function supports more values than 180.0 degrees, but considering the purposes it is used for, more than 45 degrees of rotation are probably unnecessary at all.
.

Open loop: closed-loop correction is disabled because the feedback angle is not in the same frame as the command.

Parameters
S1_Target_DegServo 1 angle (deg, before offset).
S2_Target_DegServo 2 angle (deg, before offset).

0.00 degrees corresponds to no angle of attack. Positive angle corresponds to positive roll moment, and vice versa.
