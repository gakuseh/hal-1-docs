Detailed Description

Extended Kalman filter built on the Physics model.

State x = [ω1, ω2, ω3, v1, v2, v3, qw, qx, qy, qz]: body angular rates (rad/s), body velocity (m/s), and attitude quaternion. Measurement y = [ax, ay, az, gx, gy, gz]: accelerometer (g) and gyroscope (rad/s).

The prediction integrates Physics::eom() with one Euler step and propagates the covariance through a numerical Jacobian. The correction limits which measurements can update which states (see correct_()). Before t_rail the state is held to the launch rail.

Owned by CTRLs_STATESPACE() as a function-local static.

Measurement update with gain limiting and a Joseph-form covariance update.

Accelerometer innovations may correct only velocity, gyroscope innovations only angular rates, and nothing corrects the quaternion. While burning, the accelerometer noise is raised to accel_burn_std_g and its gains are zeroed entirely.
