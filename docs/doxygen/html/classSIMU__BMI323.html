Detailed Description

One BMI323 accelerometer and gyroscope, configured for flight.

Init() runs both at 200 Hz: the accelerometer at ±16 g with 64-sample averaging (50 Hz bandwidth), the gyroscope at ±2000 deg/s with no averaging (100 Hz bandwidth).

◆ Update()

int SIMU_BMI323::Update ( )

Reads a new sample if one is ready.

Returns 0 without reading unless the accelerometer, gyroscope and temperature data-ready flags are all set. New data arrives every 5 ms and the sensor task polls every 2 ms. The temperature is read but discarded.

Returns
0 on success or when no sample is ready; -999 if Init() has not succeeded; otherwise a negative Bosch BMI3 error code.
