Detailed Description

Rocket model for the controller: fixed-size matrices, rocket parameters, and the 6-DOF physics.

Physics implements the equations of motion that the EKF predicts with and that ControlLaw uses for its gain. The model and its constants are ported from the FV-Controls simulation for the Control Freak rocket.

◆ loadControlFreakRocketConfig()

void loadControlFreakRocketConfig ( RocketConfig & cfg)

Loads the Control Freak flight parameters into cfg.

Values come from the FV-Controls RocketPy setup: masses, inertias, CG, aerodynamics, controller limits (9° deflection, about 429°/s rate), EKF noise, the launch attitude for a 45° rail, the roll effectiveness monitor (enabled), and the thrust and drag tables. Call computeDerived() afterwards.

Parameters
[out]cfgConfig to fill.
