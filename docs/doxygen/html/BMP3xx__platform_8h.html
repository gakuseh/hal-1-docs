Detailed Description

SPI and delay callbacks that connect the Bosch BMP390 driver to the STM32 HAL.

Each of the three barometers has its own TX/RX buffer pair. Transfers are blocking HAL calls with a 5 s timeout.

int8_t BMP_SPI_Read ( uint8_t reg_addr,
uint8_t * data,
uint32_t len,
void * ptr )

Bosch read callback: reads len bytes starting at register reg_addr.

Sends reg | 0x80, clocks len + 1 bytes, and copies everything after the address byte into data. The Bosch driver already adds the BMP390's dummy byte to len.

Parameters
reg_addrRegister address.
[out]dataDestination.
lenNumber of bytes to read.
ptrThe sensor's bmp3_spi_intf.
Returns
Always 0, even if the SPI transfer failed.
