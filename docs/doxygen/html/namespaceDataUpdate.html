void DataUpdate::FuseAttitude ( stateestimation::AttitudeEstimator * est)

Runs one attitude-estimator step and writes the quaternion and Euler angles into g_telemNow.

Feeds the gyro (converted to rad/s) and accelerometer from g_telemNow, with no magnetometer. Does nothing while g_dt is 0.

Parameters
estThe estimator owned by updateDataTask().
Warning
The roll and yaw assignments do not match the comment above them in the source. The comment maps eulerYaw() to physical roll, but the code stores eulerPitch() in roll and eulerYaw() in yaw. Pitch matches. Check on the bench which one is right.

◆ getVerticalVelocity()

float DataUpdate::getVerticalVelocity ( )

Vertical velocity (m/s) from barometric altitude differences.

Samples g_telemNow.altitude at most every VVEL_UPDATE_PERIOD_MS and returns the previous value in between. Altitude changes under 0.1 m read as zero, so speeds below about 2 m/s report 0. Clamped to ±300 m/s.

Returns
Vertical velocity, positive up. 0 on the first call.
