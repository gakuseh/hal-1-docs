Detailed Description

The Sensors aggregate that reads every sensor and publishes g_telemNow and g_SensorData.

FlightComputer_SENSORS.cpp also defines the shared globals g_telemNow, g_telemPrev, g_gndData, g_BMI, g_BMP, g_GPS and g_servoAngles.
