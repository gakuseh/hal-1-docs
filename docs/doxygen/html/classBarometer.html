Detailed Description

One BMP390 barometer, configured for flight.

Init() sets normal mode at 100 Hz with 2× oversampling on pressure and temperature.

◆ Update()

uint8_t Barometer::Update ( )

Reads a new sample if one is ready and converts it to altitude.

Keeps the previous reading if no new sample is ready, or if the pressure is outside BARO_PRESS_MIN_PA to BARO_PRESS_MAX_PA. Altitude uses the standard barometric formula, 44330 × (1 − (p / 101325)^0.1903).

Returns
0 on success or when no new sample is ready; 1 not initialized or status read failed; 2 data read failed; 3 status re-read failed.
