uint32_t micros ( void )

Microseconds since the DWT counter was reset.

Warning
The cycle counter wraps every 2³² cycles (about 8.9 s at 480 MHz). Because this divides before wrapping, the difference of two readings is wrong across a wrap. Subtract raw DWT->CYCCNT values instead, as DataUpdate::ComputeDt() does.
