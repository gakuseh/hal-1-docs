Detailed Description

ISM6HG256X accelerometer, high-g accelerometer and gyroscope.

Update() accumulates samples while the data-ready interrupt flag is set and publishes averages every 100 low-g samples (about every 1.7 s at 60 Hz).

◆ Init()

int8_t IMU_ISM6HGx::Init ( )

Resets the chip, checks WHO_AM_I, and applies the config.

Low-g accelerometer 60 Hz ±2 g, high-g accelerometer 960 Hz ±256 g, gyroscope 120 Hz ±2000 deg/s, with low-pass filtering and high-g data-ready routed to INT1.

Returns
0 on success, -1 if WHO_AM_I does not match.
